# Marketing Performance Dashboard

## 📊 Project Overview

The Marketing Performance Dashboard is a data analytics project developed to analyze digital advertising campaign performance.

The dashboard helps analyze marketing campaigns, customer engagement, marketing channels, conversions, revenue and advertising efficiency through interactive visualizations.

## 🎯 Objectives

- Analyze marketing campaign performance
- Compare different marketing platforms
- Calculate important marketing KPIs
- Analyze campaign objectives
- Study monthly performance trends
- Generate business insights from marketing data
- Provide downloadable marketing reports

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
- GitHub

## 📈 Key Performance Indicators

The dashboard analyzes:

- Impressions
- Clicks
- Conversions
- Click-Through Rate (CTR)
- Conversion Rate
- Advertising Spend
- Revenue
- Profit
- Return on Ad Spend (ROAS)

## 📊 Dashboard Features

- Interactive platform selection
- Campaign objective selection
- Marketing KPI cards
- Platform performance comparison
- Campaign objective analysis
- Monthly revenue trends
- Monthly ROAS trends
- Business insights
- Performance tables
- CSV report downloads
